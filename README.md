# Hospital Bed & ICU Allocation Dashboard

## Overview

The Hospital Bed & ICU Allocation Dashboard is a healthcare management system designed to support real-time hospital bed management and emergency patient allocation.

The system monitors ward and ICU bed occupancy, prioritizes patients for ICU transfers based on their triage severity, and supports inter-facility ambulance transfer workflows.

## Key Features

- Real-time monitoring of hospital and ICU bed occupancy
- Triage severity-based patient prioritization
- ER and ICU bed allocation
- Inter-facility transfer management
- Ambulance transfer coordination
- Real-time dashboard updates

## Actors

- Triage Nurse
- Hospital Administrator
- Ambulance Coordinator
