### Lab 4 – VibeCoding

**Project:** Scenario 19 – Battleship vs AI

This lab focuses on **AI-assisted software development using GitHub Copilot**.

The existing terminal-based Python Battleship game was analysed, debugged, and enhanced through incremental AI-assisted development.

Key tasks completed:

- **Task 1 – Consistent Coordinate Handling:** Fixed coordinate inconsistencies between user input, ship placement, player shots, and AI shots.
- **Task 2 – Complete Fleet & Win Logic:** Added multiple ships, individual damage tracking, sinking detection, repeated-shot prevention, and fleet win logic.
- **Task 3 – Improved AI:** Added hit-aware targeting, nearby untried-cell prioritization, duplicate-shot prevention, and safe handling of exhausted choices.
- **Task 4 – Shot-Level Feedback:** Added consistent HIT, MISS, and SUNK feedback for actual player and AI shots while keeping AI candidate selection silent.

The lab also includes before/after gameplay recordings and the complete GitHub Copilot chat history.
